# 003. 소음 알림 판정: "1.5초 안에 합계 1초 이상"

- 날짜: 2026-09-29
- 상태: 채택

## 배경
CLAUDE.md §4-3: "임계값 초과가 1초 이상 지속 시 1회 알림, 이후 30초 쿨다운."

"지속"을 엄격하게(1초 동안 한 프레임도 빠짐없이) 해석하면, 울음 사이 숨 쉬는 틈이나
연속 박수 사이의 조용한 순간에 매번 카운트가 0으로 돌아가 알림이 늦거나 안 온다.

## 결정
`shared/NoiseDetector` (순수 Kotlin, 100ms 프레임 단위):

| 항목 | 값 | 상수 |
|---|---|---|
| 임계값 | -35 dBFS (이상이면 "큼") | `Alert.DEFAULT_THRESHOLD_DBFS` |
| 판정 구간 | 최근 1.5초 (15프레임) | `Alert.SUSTAIN_WINDOW_MS` |
| 필요한 누적 시간 | 1.0초 (10프레임) | `Alert.SUSTAIN_MS` |
| 쿨다운 | 30초 | `Alert.COOLDOWN_MS` |

- 알림을 내면 판정 구간을 비운다 → 다음 알림도 1초를 새로 채워야 한다.
- 알림 본문의 `level` 은 판정 구간의 최대 dBFS.

## 이유
- 소리가 **최소 1초는 커야** 알림 → "1초 이상" 의미를 지킨다.
- 1.5초 구간이라 중간 틈을 **합계 0.5초까지** 허용 → 울음·연속 박수를 놓치지 않는다.
- 문 닫는 소리(0.4초), 짧은 기침(0.9초)은 알림 없음 (테스트로 고정).

## 기각한 안
- **1초 구간 중 50% 이상** (첫 구현): 앞이 조용하면 0.5초짜리 소음에도 알림 → "1초 이상 지속"보다 느슨함. 단위 테스트에서 발견.
- **엄격한 연속 1초**: 울음 사이 틈에서 계속 리셋됨.

## 임계값 -35 dBFS 근거
Phase 2~3 실측 (Galaxy Watch7): 조용한 방 -55 ~ -61 dBFS, 박수 최대 -11 dBFS.
기기·방마다 다르므로 Phase 6 설정 화면에서 조정 (`/control SET_THRESHOLD`).
