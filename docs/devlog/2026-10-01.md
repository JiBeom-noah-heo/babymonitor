## Baseline profile (`chore/baseline-profile`, ADR 009)
배터리 1시간 10% 는 `cmd package compile -m speed` 로 미리 컴파일한 상태였다. 실제 설치는 기기가 쉴 때까지 JIT 로 돈다
→ 앱에 baseline profile 을 넣어 설치 직후(Play) 또는 첫 최적화 때부터 오디오 루프가 컴파일되게 했다.

- `profileinstaller` + `android-common/src/main/baseline-prof.txt` (앱 코드 전체, 코루틴, JSON)
- 빌드 확인: APK `assets/dexopt/baseline.prof` 를 풀어 보니 워치 hot 메서드 31,836 → 39,186, 클래스 4,922 → 6,235
  - 규칙을 넣었는데 파일은 7,833 → 7,361 바이트로 오히려 작아짐 (연속 범위라 압축이 잘 됨) → 크기로 판단하면 안 됨
- 기기 확인: 두 기기 모두 앱 실행 시 `ProfileInstaller: Installing profile`, `compile -m speed-profile` 후 `status=speed-profile`
