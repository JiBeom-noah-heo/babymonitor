## 배경
CLAUDE.md 개정: 어느 기기가 아이 옆에 있을지 사용자가 고른다 (시나리오 A 워치=감지기 / B 폰=감지기).

## 막힌 점 / 해결
- **lint `InvalidFragmentVersionForActivityResult`**: play-services 가 fragment 1.0.0 을 끌어옴 → fragment 1.8.5 명시 (targetSdk 와 무관, Phase 3 부터 있던 문제)
- **코루틴 테스트**: `backgroundScope` 로 돌린 엔진은 `advanceUntilIdle()` 로 진행되지 않음 → `runCurrent()`
- shared 타입의 nullable 프로퍼티는 다른 모듈에서 스마트 캐스트 불가 → 지역 변수로 받기
- 버전 카탈로그에 이전 편집으로 `androidx-activity-compose ={` (공백 빠짐)가 있어 문자열 치환이 빗나감 → 수정

### A8 관찰 (Phase 5 참고)
- Phase 4(2026-09-29)에는 화면을 끄고 약 7초 뒤 스트림이 완전히 멈췄는데, 이번에는 멈추지 않음
- 달라진 점: 워치 Wi-Fi 켜짐(CLAUDE.md §7 체크리스트의 "항상 켜기" 가능성), targetSdk 33→34. 원인은 미확인
- 데이터가 몰려 들어와(버스트) 재동기화·끊김이 많음 → 연속 재생 품질은 Phase 5 에서 측정
- 그래서 "10초 무데이터 → 연결 끊김 문구" 수정(Phase 4 마지막)은 여전히 실기기 미확인
